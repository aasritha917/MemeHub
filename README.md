# 🎉 MemeHub

MemeHub is a fun and interactive meme-sharing web application where users can explore trending memes, create and share their own memes, view personalized profiles, and maintain their meme gallery.

The application provides an image-focused and user-friendly interface while using Firebase for authentication and data storage. The project was developed collaboratively as a group project, providing hands-on experience with frontend development, Firebase integration, responsive UI design, and team-based development.

## ✨ Features

### 🏠 Home Page

Browse the latest memes through a clean and engaging feed layout.

### 🔍 Explore Page

Discover new and trending memes through the explore section.

### 🎨 Meme Creation

Create personalized memes by adding content to images through the meme creation interface.

### 👤 Profile Page

View user information and uploaded memes through a personalized profile and meme gallery.

### 🔐 Firebase Integration

Uses Firebase for user authentication and application data storage.

## 🚀 Getting Started

### Prerequisites

Make sure you have:

* A modern web browser
* Git installed
* A Firebase project configured for the application

### Installation

1. Clone the repository:

```bash
git clone https://github.com/aasritha917/MemeHub.git)
```

2. Navigate to the project directory:

```bash
cd meme-hub
```

3. Configure Firebase using your project's Firebase configuration.

4. Open the application using a local development server.

5. Open the application in your browser and explore the MemeHub features.
